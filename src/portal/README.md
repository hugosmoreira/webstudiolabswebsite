# Client Portal (placeholder)

These components reserve structure for the **future** WebStudioLabs client portal.
They are intentionally minimal placeholders — the portal is **not built yet** and is
**not** wired into the public landing page or any router.

Planned portal features (future work, pending approval):

- Client login / authentication
- Project dashboard
- Subscription status & billing
- Messages
- Files & deliverables
- Support tickets
- Platform access
- Admin dashboard

Backend, auth, billing provider, and database are intentionally **out of scope**
for the current frontend deliverable.

## Files

| File | Purpose |
| --- | --- |
| `PortalPlaceholder.jsx` | Shared placeholder shell used by every screen below |
| `DashboardHome.jsx` | Portal home / overview |
| `ProjectOverview.jsx` | Active project scope & progress |
| `Roadmap.jsx` | Development roadmap & milestones |
| `Messages.jsx` | Client ↔ team messaging |
| `Files.jsx` | Files & deliverables |
| `Billing.jsx` | Subscription & invoices |
| `SupportRequests.jsx` | Support tickets |
| `Settings.jsx` | Account & access settings |
